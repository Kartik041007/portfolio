# VELLOX — Responsive website



## Run
Open `index.html` in your browser, or open the folder in VS Code and start Live Server. No build step required. Google Fonts load from the internet; fallback fonts work offline.

## Important before publishing
- The PDF doesn't provide a verified dealer address, phone number, email, or ordering link. The footer uses `hello@vellox.example` as an **inactive placeholder**; replace it with the actual brand email.
- Technical and certification claims reproduce the provided PDF and should be independently confirmed by the brand before publishing.
- The PDF does not provide downloadable font files; this implementation uses Google Fonts approximations.
- Colourway selection is a visual selector, not an ecommerce cart.
